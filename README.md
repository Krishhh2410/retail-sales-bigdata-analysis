\# Retail Sales Data Warehouse Analysis



\## Project Overview



This project develops a distributed retail sales data warehouse using a 3-node Hadoop cluster.



The project uses HDFS for distributed storage, Apache Hive for data warehousing and querying, and Apache Spark for distributed data processing and analytics.



\## Technologies Used



\- Hadoop HDFS

\- Apache Hive

\- Apache Spark

\- PySpark

\- GitHub



\## Cluster Architecture



\- 1 Master Node

\- 2 Worker Nodes



\## Main Analytics



\- Revenue by product category

\- Top-performing stores

\- Monthly sales trends

\- Regional sales analysis

\- Seasonal sales analysis



\## Project Workflow



Retail Sales Dataset

→ HDFS

→ Hive

→ Spark

→ Analytics

→ Results
